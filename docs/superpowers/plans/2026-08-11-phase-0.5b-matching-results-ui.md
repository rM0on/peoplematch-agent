# Phase 0.5B Matching Results UI Implementation Plan

> **Scope:** Implement the selected Evidence-first fusion as a design-mock frontend only. No Phase 1 schemas, APIs, ranking logic, or algorithm claims.

**Goal:** Turn the approved 1440 × 1024 visual direction into a responsive, accessible Matching Results screen that demonstrates ranking, evidence, risk, explanation, and a lightweight trace without presenting illustrative values as real output.

**Architecture:** Keep `page.tsx` as a thin composition entry. Place screen behavior and presentation in `features/matching-results`, keep illustrative records in a clearly named mock-data module, and use small typed components for the app shell, shortlist, ranking detail, evidence, and pipeline trace. Client state is limited to the visible design interactions: candidate selection, comparison disclosure, and pipeline-stage inspection.

**Stack:** Next.js 16, React 19, TypeScript, Tailwind CSS 4, Phosphor React icons, Vitest, Testing Library.
